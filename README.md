A modern, mobile-first personal finance and monthly budget management web application built with Python (Flask) and Tailwind CSS. Designed to help users track daily expenses, monitor savings, and prevent cash-flow shortages with real-time financial alerts.

🔗 **Live Website:** [ak2program.pythonanywhere.com](https://ak2program.pythonanywhere.com)

---

## 🎯 Core Features

- 📱 **Smart Financial Dashboard:** Real-time overview of Total Balance, Available Liquid Cash, Monthly Budget, Total Spent, and Total Savings.
- 💡 **Intelligent Fund Shortage Detection:** Automatically calculates cash-flow liquidity and alerts the user if their remaining budget exceeds their actual available cash.
- ⏳ **Month-Scoped Tracking:** Seamlessly switch between different months to view historical budgets, expenses, and spending trends.
- ⚡️ **Quick Expense & Savings Logging:** Add, edit, and delete daily expenses categorized by custom categories and payment methods.
- 📊 **Visual Analytics:** Interactive Doughnut charts showing category-wise expense breakdowns.
- 🌍 **Bilingual Support (EN / বাংলা):** Instant language toggle supporting both English and Bengali.
- 💎 **Modern Responsive UI:** Clean dark-mode interface that works smoothly across mobile devices and desktops.
- 🔒 **Admin Portal:** Role-based access control to monitor registered users and manage system health.
- 💾 **Data Export:** Export financial records in CSV (with UTF-8 BOM for proper Bengali rendering in Excel) and JSON formats.

---

## ⚙️ Tech Stack

- **Backend:** Python, Flask, Flask-Login, Flask-WTF
- **Database:** SQLite / PostgreSQL (Flask-SQLAlchemy)
- **Frontend:** HTML5, Jinja2, Tailwind CSS, Vanilla JavaScript, Chart.js
- **Hosting:** PythonAnywhere
